# .github · Pyro-Alert

Repositório especial do GitHub: o arquivo [`profile/README.md`](profile/README.md) é exibido na
página pública da organização, [github.com/Pyro-Alert](https://github.com/Pyro-Alert).

- O nome `.github` é exigido pelo GitHub, por isso este repositório não segue o prefixo `pyro-`.
- Ele é **público**: tudo aqui pode ser lido por qualquer pessoa. Nada de detalhes internos
  (endereços, portas, configurações, segredos). A documentação técnica fica nos repositórios `pyro-*`.
- Para mudar a página da organização, edite `profile/README.md` numa branch e abra um PR.
